شرح الدرس: الـ Gradient Descent

١. يعني إيه الـ Gradient Descent؟

الـ gradient descent هو الخوارزمية اللي تقريبًا كل neural network بتستخدمها علشان «تتعلّم». الفكرة في الأساس بسيطة: إحنا عندنا حاجة اسمها loss function بتقيس الموديل بتاعنا غلطان قد إيه، وهدفنا إننا نخلّي الـ loss دي أصغر ما يمكن.

بنبدأ بقيم عشوائية للـ weights، وبنحسب الـ gradient بتاع الـ loss بالنسبة للـ weights. الـ gradient بيقولنا اتجاه «أكبر زيادة» في الخطأ. وبما إن إحنا عايزين نقلّل الخطأ مش نزوّده، فإحنا بناخد خطوة في الاتجاه المعاكس للـ gradient. وبنكرّر العملية دي لحد ما الـ loss توصل لأقل قيمة ممكنة.

١. الـ gradient descent بيشتغل إزاي علشان يقلّل الخطأ؟

  1. بياخد خطوة في نفس اتجاه الـ gradient
  2. بياخد خطوة في الاتجاه المعاكس للـ gradient
  3. بيغيّر الـ loss function نفسها
  4. بيختار الـ weights عشوائي كل مرة

٢. الـ Learning Rate وأهميته

حجم الخطوة اللي بناخدها في كل تكرار بيتحكم فيها رقم اسمه الـ learning rate. الرقم ده مهم جدًا:

  • لو الـ learning rate كبير أوي، ممكن نتخطّى أقل نقطة (الـ minimum) ونلفّ حواليها من غير ما نوصلها — يعني مفيش convergence.
  • لو صغير أوي، التدريب هيكون صح بس بطيء جدًا وهياخد وقت طويل.

٢. لو الـ learning rate كبير جدًا، إيه أكتر حاجة ممكن تحصل؟

  1. التدريب يبقى بطيء جدًا
  2. نتخطّى الـ minimum ومنوصلش لـ convergence
  3. الـ loss تثبت من أول خطوة
  4. مفيش أي تأثير على التدريب

مفتاح الإجابات

  1. السؤال ١: B — لأن إحنا عايزين نقلّل الخطأ، فبناخد خطوة عكس اتجاه الـ gradient (اللي بيشاور على الزيادة).
  2. السؤال ٢: B — الـ learning rate الكبير بيخلّينا «نقفز» فوق أقل نقطة فمنستقرش عندها.
